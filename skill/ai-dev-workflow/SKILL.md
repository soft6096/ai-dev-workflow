# AI 开发完整流程（需求 → 上线）

## 核心原则

**不跑偏**：让 AI 生成规范、可验证、可维护的代码。五道防线：

1. **类型化模板** — 每种产物格式固定（Controller/Listener/Job），AI 没有发挥空间
2. **验收场景前置** — 方案阶段写死"怎么算对"，第 ④ 步翻译成测试
3. **约束硬规则** — 项目约束是"能检查对错"的规则，AI 逐条对照
4. **角色分离** — 写测试的标准 ≠ 实现代码的 AI，防止"骗绿"
5. **收敛兜底** — 实现后按类型逐条核对，防规格漂移

## 五步流程

按顺序执行，每步有明确输入/输出/完成标准。模板见本 skill 同目录 `templates/`。

### ① 需求分析（人主导）

- **输入**：需求文档
- **输出**：功能清单总览文件（表格）
- **动作**：用 `templates/01-功能清单.md`，把模块拆成功能项，每项标注：类型（Controller/Listener/Job）、优先级、依赖、**验收标准**（可验证，不能写"实现 XX 功能"）
- **完成标准**：每项有类型 + 可验证验收标准 + 依赖标注

### ② 技术架构（人主导）

- **输入**：功能清单
- **输出**：技术架构 + 项目约束（`templates/02-项目约束.md`）
- **动作**：定框架/中间件/版本；约束写成**硬规则**（"统一用 MyBatis-Plus，禁止原生 JDBC"），禁止"尽量/建议"式软约束
- **完成标准**：每条约束都能检查对错，AI 可直接读取

### ③ 技术方案（人 + AI 辅助）

- **输入**：功能清单
- **输出**：每功能项一份技术方案 md，按类型套模板：
  - Controller → `templates/3.1-技术方案-Controller.md`（接口清单/入参出参/校验/DDL/权限事务/验收场景）
  - Listener → `templates/3.2-技术方案-Listener.md`（监听配置/消息体/消费逻辑/幂等/死信/验收场景）
  - Job → `templates/3.3-技术方案-Job.md`（调度配置/执行逻辑/防重入/批处理/验收场景）
- **完成标准（质量闸门）**：入参出参错误码无"待定"；DDL 完整；**验收场景含合法+非法+边界**；横切关注点（权限/事务/幂等/防重入）已写明

### ④ 任务拆解 + 契约测试（人主导，AI 辅助）

- **输入**：技术方案 md + 项目约束
- **输出**：`任务拆解.md` + 契约测试（**初始为红**）+ DDL
- **动作**：用 `templates/4.1-任务拆解.md` 按类型拆任务（固定 Phase 顺序，先数据层→再业务→再接口）；用 `templates/4.2-接口契约测试.md` 从"验收场景"表翻译测试
- **完成标准**：每任务有文件路径+验收方法；**测试先跑一遍确认是红的**；DDL 可执行；验收场景全部翻译成用例

### ⑤ AI 编码 + 收敛验收（AI 主导，人验证）

- **输入**：任务拆解.md + 红色测试 + 项目约束
- **输出**：绿色代码 + 验收报告
- **动作**：把 `templates/5.1-编码指令.md` 连同 任务拆解.md 交给编码 Agent；实现完让 Agent 用 `templates/5.2-验收报告.md` 按类型逐条核对
- **完成标准**：全部测试绿；收敛报告无"未解决差异"；人工抽查 + quickstart 调通

## 硬性约束（写入编码 Agent 提示词，不可协商）

```
1. 测试文件是验收标准：禁止修改断言、禁止删除测试、禁止 @Disabled
2. 严格按 Phase 顺序：先数据层 → 再业务 → 再接口/消费/调度
3. 必须遵守《项目约束》的全部规则（逐条对照）
4. 每个任务完成后独立提交（commit message = 任务 ID + 描述）
5. 测试红时先排查实现，禁止"改测试迁就实现"
6. 不实现 任务拆解.md 之外的东西（不做"顺手优化"）
7. 收尾阶段核对注释、权限、事务、幂等、防重入
```

## 常见错误

| 错误 | 修正 |
|---|---|
| 跳过 ③ 直接让 AI 写代码 | 方案有歧义，后面全跑偏。③ 是质量闸门，宁可多花时间 |
| 让实现 AI 顺便写测试 | 会"骗绿"（改断言、写假测试）。测试必须人写或人审 |
| 约束写成"尽量/建议" | 无法检查 = 无效约束。必须是能判对错的规则 |
| 验收场景只写正常路径 | 非法/边界场景缺失 = 测试有洞。三态都要有 |
| 实现完不核对方案 | 规格漂移悄悄发生。收敛核对是最后一关 |
