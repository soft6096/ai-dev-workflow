# 技术方案（Controller）

为功能清单中的某个 Controller 功能项生成技术方案。

## 输入

- 功能清单中的对应功能项（含验收标准）
- 项目约束（`docs/项目约束.md`）

## 执行

1. 按模板 `templates/3.1-技术方案-Controller.md` 生成，包含：

- **接口清单**：方法/路径/入参/出参/对应 Service/错误码
- **入参 JSON 示例** + **出参 JSON 示例**（成功/失败/分页）
- **入参校验规则**：必填/格式/长度/枚举/唯一
- **数据模型 DDL**：建表 + 关联表 + 查询 SQL（字段/类型/索引/注释）
- **权限与事务**：@RequiresPermissions、@Transactional 边界
- **验收场景**：合法 + 非法 + 边界（测试用例蓝本）
- **注释要求**

## 输出

`docs/技术方案/<功能名>.md`（每功能项一份）

## 完成标准（质量闸门）

- [ ] 接口路径/方法/入参出参/错误码无"待定/视情况"
- [ ] 每个接口有入参 + 出参 JSON 示例
- [ ] DDL 完整（表 + 关联表 + 索引 + 查询 SQL）
- [ ] 验收场景含合法 + 非法 + 边界
- [ ] 权限/事务对照项目约束逐条检查
