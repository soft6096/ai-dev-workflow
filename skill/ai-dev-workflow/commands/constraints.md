# 项目约束（技术架构）

根据功能清单，确定技术架构并生成**项目约束文件**。

## 输入

- 第①步的功能清单
- 用户的技术栈偏好（可选）

## 执行

1. 确定技术架构总览：

| 类别 | 选型 | 版本 | 说明 |
|------|------|------|------|
| 开发框架 | | | |
| ORM | | | |
| 数据库 | | | |
| 缓存/消息/调度 | | | |

2. 生成**硬性约束**（每条必须能检查对错，禁止"尽量/建议"）：

```markdown
1. 统一使用 XX，禁止 YY
2. 所有新增接口必须加 @RequiresPermissions 权限注解
3. 数据库操作统一走 Service 层
4. 涉及多表写入必须 @Transactional
...
```

## 输出

`docs/项目约束.md`（参考模板 `templates/2.1-项目约束.md`）

## 完成标准

- [ ] 每条约束是"能检查对错"的规则
- [ ] 版本号已写死
- [ ] 覆盖：编码规范/事务/权限/日志/幂等/防重入
