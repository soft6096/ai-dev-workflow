# 验收报告（收敛核对）

全部测试变绿后，对照技术方案逐条核对实现，输出**验收报告**。

## 输入

- 第③步的技术方案 md
- 已实现的代码 + 测试结果

## 执行

1. 按模板 `templates/5.2-验收报告.md` 生成核对报告，按类型逐条核对：

**Controller 核对**：

| 核对项 | 对照来源 | 常见漂移 |
|---|---|---|
| 接口路径/方法/入参出参 | 技术方案接口清单 | AI 改参数名、漏字段 |
| 校验规则 | 技术方案入参校验 | 校验缺失或过严 |
| 表名/字段/类型/索引 | 技术方案 DDL | AI 自创列名 |
| Service 映射 | 技术方案接口清单 | 调错 Service 方法 |
| 权限/事务 | 项目约束 | 漏 @RequiresPermissions |

**Listener 核对**：队列/路由键/ACK、幂等逻辑、死信/重试、消息体校验
**Job 核对**：cron/调度、防重入锁、批处理、失败告警

2. 核对出差异 → 追加为新任务（T009…）→ 返回 /implement 继续 → 再跑测试

## 输出

`docs/<模块名>/<功能名>-验收报告.md`

## 完成标准

- [ ] 全部核对项 ✅ 或差异已追加任务处理
- [ ] 验收报告无"未解决差异"
- [ ] 人工抽查核心逻辑 + quickstart 调通
- [ ] 功能清单逐项打勾，确认覆盖
