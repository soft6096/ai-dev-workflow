# 技术方案（Listener）

为功能清单中的某个 Listener（MQ 消费者）功能项生成技术方案。

## 输入

- 功能清单中的对应功能项（含验收标准）
- 项目约束（`docs/项目约束.md`）

## 执行

1. 按模板 `templates/3.2-技术方案-Listener.md` 生成，包含：

- **监听配置**：交换机/队列/路由键/消费组/ACK 方式
- **消息体结构**：JSON 示例 + 字段约束（必填/类型/枚举）
- **消费逻辑主流程**：校验 → 幂等 → 更新 → 日志 → ACK
- **幂等与失败处理**：唯一键方案 + 重试次数 + 死信队列
- **涉及 Service 和表**（含幂等唯一索引 DDL）
- **边界场景**：重复/乱序/缺字段
- **验收场景** + **注释要求**

## 输出

`docs/技术方案/<功能名>.md`（每功能项一份）

## 完成标准（质量闸门）

- [ ] 交换机/队列/路由键/ACK 方式明确
- [ ] 消息体 JSON 示例 + 字段约束完整
- [ ] 幂等方案 + 唯一索引 DDL 明确
- [ ] 失败处理（重试次数 + 死信队列）明确
- [ ] 验收场景覆盖正常/重复/非法/失败/乱序
