# AI 编码

按任务拆解.md 顺序实现代码，目标：**让全部测试变绿**。

## 输入

- 第④步的任务拆解.md + 红色契约测试
- 项目约束（`docs/2.1-项目约束.md`）
- 技术方案（作为实现依据）

## 执行规则（硬性约束，不可协商）

```
1. 测试文件是验收标准：禁止修改断言、禁止删除测试、禁止 @Disabled
2. 严格按 Phase 顺序：先数据层 → 再业务 → 再接口/消费/调度
3. 必须遵守《项目约束》的全部规则（逐条对照）
4. 每个任务完成后独立提交（commit message = 任务 ID + 描述）
5. 测试红时先排查实现，禁止"改测试迁就实现"
6. 不实现任务拆解.md 之外的东西（不做"顺手优化"）
7. 收尾阶段核对注释、权限、事务、幂等、防重入
```

## 输出

- 通过测试的代码（每个任务独立 commit）
- 测试结果汇总（通过/失败）

## 完成标准

- [ ] 全部测试绿
- [ ] 未修改任何测试文件（断言/用例）
- [ ] 遵守项目约束全部规则
- [ ] 每个任务独立提交
