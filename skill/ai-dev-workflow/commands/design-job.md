# 技术方案（Job）

为功能清单中的某个 Job（定时任务）功能项生成技术方案。

## 输入

- 功能清单中的对应功能项（含验收标准）
- 项目约束（`docs/项目约束.md`）

## 执行

1. 按模板 `templates/3.3-技术方案-Job.md` 生成，包含：

- **调度配置**：Quartz Job 类 + cron 表达式 + 触发说明
- **执行逻辑主流程**：防重入 → 筛选 → 逐条处理 → 日志 → 释放锁
- **并发与锁**：分布式锁 + 批处理大小（避免长事务）
- **查询 SQL** + **涉及 Service 和表**（含执行日志表 DDL）
- **异常与告警**：单条隔离 + 失败率阈值
- **验收场景** + **注释要求**

## 输出

`docs/技术方案/<功能名>.md`（每功能项一份）

## 完成标准（质量闸门）

- [ ] cron 表达式 + 调度注册方式明确
- [ ] 防重入方案（分布式锁/状态位）+ 锁超时明确
- [ ] 批处理大小明确，避免长事务
- [ ] 查询 SQL 写全（筛选条件 + LIMIT）
- [ ] 失败处理（单条隔离 + 告警阈值）明确
- [ ] 验收场景覆盖正常/并发/空数据/部分失败
