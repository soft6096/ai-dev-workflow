# 技术方案：订单超时关闭（US-003）

> 使用说明：这是第 ③ 步"技术方案"的产物模板（Job 类型，定时任务）。
> 防重入和批处理是 Job 的**生死线**——并发触发、长事务、单条失败拖垮批量必须在方案里写死。
> 下方内容为**完整示例**（订单超时关闭），复制后替换成你的业务数据。

## 基本信息

- 功能项：#4 | 类型：Job | 优先级：P2 | 依赖：#1

## 调度配置

- Quartz Job 类：OrderTimeoutJob
- cron 表达式：`0 */5 * * * ?`（每 5 分钟执行一次）
- 触发器说明：每分钟扫描一次 sys_order，关闭超过 30 分钟未支付的订单

## 执行逻辑（主流程）

1. 防重入检查：获取分布式锁（Redis SETNX order.timeout.lock EX 600）
   - 获取失败 → 说明已有实例在跑，直接返回
2. 查询超时订单：

```sql
SELECT order_id FROM sys_order
WHERE status = 'PENDING'
  AND create_time < DATE_SUB(NOW(), INTERVAL 30 MINUTE)
  AND del_flag = '0'
ORDER BY create_time ASC
LIMIT 500
```

3. 逐条处理（每条独立事务）：
   - 关闭订单（status → CLOSED）
   - 释放库存（调用 StockService.releaseStock(orderId, items)）
   - 写 job_execution_log
4. 统计本次处理条数、耗时，写入执行日志
5. 释放分布式锁

## 并发与锁

- 防重入：Redis 分布式锁，key=order.timeout.lock，超时 600s（10 分钟 > 单轮执行时间）
- 批处理：每次最多 500 条，避免长事务；500 条处理完若还有剩余，等下次调度

## 涉及 Service 和表

- OrderService.closeTimeoutOrders()
- StockService.releaseStock()
- 表：sys_order（status 字段）、job_execution_log（执行日志，DDL 见下）

```sql
-- Job 执行日志表
CREATE TABLE job_execution_log (
  id           BIGINT PRIMARY KEY AUTO_INCREMENT,
  job_name     VARCHAR(50) NOT NULL COMMENT '任务名',
  execute_time DATETIME NOT NULL COMMENT '执行时间',
  process_count INT DEFAULT 0 COMMENT '处理条数',
  cost_ms      BIGINT DEFAULT 0 COMMENT '耗时（毫秒）',
  remark       VARCHAR(255) DEFAULT '' COMMENT '备注'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='Job执行日志';
```

## 异常与告警

- 单条失败不影响批量：逐条 try-catch，失败记日志（remark 记录失败原因）
- 批量失败率 > 20% → 发送告警（钉钉/邮件，走 AlertService）

## 验收场景

| # | 场景 | 期望 |
|---|------|------|
| 1 | 手动触发 | 超时订单被关闭（status=CLOSED），日志记录条数正确 |
| 2 | 并发触发两次 | 只执行一次（第二次获取锁失败直接返回） |
| 3 | 无超时订单 | 正常结束，日志 0 条 |
| 4 | 单条释放库存失败 | 不影响其他条，失败条记日志，订单不关闭（保持 PENDING） |

## 公共组件识别（架构自检结果）

> 用途：防重复代码。方案期识别本功能重复/可复用逻辑，设计公共组件，供第 ④ 步拆任务时排入 Phase 0.5。
> 判定：无状态纯逻辑 → 工具类（common/util/）；有状态/模板方法 → 抽象基类（common/base/）。
> 无重复逻辑 → 填"无"。

| # | 重复/可复用逻辑 | 使用点 | 抽取类型 | 设计（签名/继承关系/包） |
|---|----------------|--------|----------|--------------------------|
| 1 | Redis 分布式锁获取/释放 | 本 Job + 其他 Job | 工具类 `common/util/RedisLockUtil` | `RedisLockUtil.tryLock(key, timeoutSec)` / `unlock(key)` |
